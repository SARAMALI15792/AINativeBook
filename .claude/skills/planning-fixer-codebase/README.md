# Planning Fixer Codebase

This skill provides a comprehensive framework for analyzing and remediating unstable codebases with multiple broken features. It follows a systematic 5-phase approach: deep root cause analysis, structured remediation planning, controlled execution, system hardening, and validation.

## Usage

Use this skill when you have a deployed project with multiple broken features and instability. The skill will help you:

1. **Phase 1**: Perform deep root cause analysis and gap assessment
2. **Phase 2**: Create a structured remediation roadmap with prioritized fixes
3. **Phase 3**: Execute fixes in a controlled, validated manner
4. **Phase 4**: Harden the system with security and quality improvements
5. **Phase 5**: Validate that all issues are resolved and the system is stable

To use the analysis script:
```bash
python scripts/example_script.py <path_to_project>
```

## Resources

- `scripts/` - Contains the codebase analysis script that performs 5-phase analysis
- `references/` - Contains detailed guidelines for each phase of the remediation process
- `assets/` - Contains remediation plan templates for documentation and tracking
