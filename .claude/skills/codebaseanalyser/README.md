# Codebase Analyser Skill

Execute comprehensive deep analysis of entire codebase and deployment pipeline to identify issues in production environment. Perform systematic investigation across architecture, authentication, file connections, deployment, CI/CD, and stability.

## When to Use This Skill

Use this skill when:
- Deployed application functionality is not working correctly in production
- Need comprehensive deep analysis of entire codebase
- Authentication system issues in production
- Deployment pipeline debugging is required
- CI/CD setup for auto-testing is needed
- Stability improvements and refactoring suggestions are required
- File-level and line-level connection audits are needed

## How to Execute the Skill

Execute the following phases in order:
1. Perform full codebase architecture analysis
2. Execute deep trace of the authentication system
3. Audit file-level and line-level connections
4. Debug deployment and production issues
5. Implement CI/CD pipeline for auto-testing
6. Create stability improvement plans

## Key Capabilities

- **Architecture Analysis**: Identify frontend, backend, database, and authentication components
- **Authentication Deep Trace**: Check login flow, tokens, CORS, environment differences
- **Connection Audit**: Verify API routes, controllers, middleware, and dependencies
- **Deployment Debugging**: Analyze build process, environment variables, server config
- **CI/CD Setup**: Provide GitHub Actions workflow templates for continuous testing
- **Issue Categorization**: Organize issues by criticality (Critical, Major, Minor)
